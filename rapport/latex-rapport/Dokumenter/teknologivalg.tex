\section{Teknologivalg}
I dette kapitel præsenteres de teknologier, værktøjer, frameworks m.m. der er anvendt til projektet
og de overvejelser der er gjort.
Valgene begrundes ud fra projektets krav, vores egne kompetencer og ønsket om en robust og vedligeholdelsesvenlig løsning.

Der findes allerede velkendte og populære tech stacks, som der også vil blive lagt vægt på.
Fordelen ved at bruge en velkendt tech stack er, at der er større mulighed for at finde løsninger på problemer, der måtte opstå.
De tech stacks der er blevet lagt vægt på er:
\begin{itemize}
    \item MERN-stack
    \begin{itemize}
        \item MongoDB, Express, React, Node.js
    \end{itemize}
    \item LAMP-stack
    \begin{itemize}
        \item Linux, Apache, MySQL, PHP
    \end{itemize}
    \item PORN-stack
    \begin{itemize}
        \item Phoenix, Oracle, React, Nginx
    \end{itemize}
    \item PERN-stack
    \begin{itemize}
        \item PostgreSQL, Express, React, Node.js
    \end{itemize}
\end{itemize}
Nogen virker mere intuitive end andre.
Der lægges dog vægt på alle stacks i processen, og hver stack vurderes ud fra de fordele og ulemper, den tilbyder.
